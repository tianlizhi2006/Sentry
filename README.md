# 哨兵遥控工程

本工程基于 STM32H723 和 FreeRTOS，用于哨兵底盘、双 Yaw 云台及发射机构的遥控演示和实机调试。

## 已完成功能

- 四全向轮底盘控制：4 个 3508 电机，CAN2，支持普通模式和小陀螺模式。
- 以云台朝向作为底盘前方，左摇杆控制前后、左右平移。
- 双 Yaw 云台控制：大 Yaw 为 DM4310，小 Yaw 为 GM6020，Pitch 为 DM4310。
- 云台 IMU 角度和角速度串级闭环，小 Yaw 软限位，大 Yaw 自动回中及小陀螺前馈。
- 摩擦轮和拨弹盘控制：摩擦轮到速后才允许拨弹，并带 CAN 反馈失联保护。
- CAN1、CAN2、CAN3 发送互斥，避免多个任务同时发送时覆盖帧 ID。

## 遥控方式

- 右拨杆下：整车无力。
- 右拨杆中：普通模式。
- 右拨杆上：小陀螺模式。
- 普通模式下，左拨杆下：关闭发射机构。
- 普通模式下，左拨杆中：启动摩擦轮。
- 普通模式下，左拨杆上：保持摩擦轮运行，摩擦轮到速后启动拨弹盘。

## 仍需实机调整

- 底盘轮速 PID、最大移动速度、小陀螺转速和功率参数。
- 全向轮运动学方向及下地后的直线、横移和旋转效果。
- 大 Yaw、小 Yaw、Pitch 的 PID、机械零点、重力补偿和小陀螺前馈。
- 摩擦轮目标转速、速度 PID、轮间距及弹道机械位置。当前目标转速为 3200 RPM。
- 拨弹盘速度 PID和实际发射频率。当前设置为约 6 发/秒。
- 拨弹盘堵转检测、停机和自动退弹逻辑尚未完成。
